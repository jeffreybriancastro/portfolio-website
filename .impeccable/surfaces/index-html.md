## Direction contract

THESIS: One operator runs a client's whole system — site, funnel, CRM, automation — not a single-service specialist. Refuses the "just a web designer" or "just an automation guy" page.

OWN-WORLD: Light, airy neutral ground (warm off-white, lavender-tinted), near-black navy ink, one committed warm amber accent carrying CTAs and live-state marks. Fixed profile/nav rail beside a free-flowing content column. Content reads as a differentiated bento composition — varied card sizes and densities, never uniform icon+heading+text tiles. Drawn line-icon system (no emoji, no stock glyphs). No kickers/eyebrows anywhere. No decorative section numbering.

STORY: Visitor reads the single-operator capability claim in one line, sees the real tool stack (GHL, n8n, Zapier, Make, Claude Code) as proof of hands-on delivery, scans service breadth (Websites / Funnels / CRM / Automation), previews clearly-labeled placeholder project slots, reaches the contact CTA within the first two screens.

FIRST VIEWPORT: Left-fixed rail — monogram mark, name "Jeffrey Brian Castro", one-line role, socials, nav — beside a hero: two-line bold headline stating the single-operator thesis, one-line subhead, tool-stack strip as inline pills (no eyebrow label above it), primary CTA in the accent color. The bento composition begins directly below the fold.

FORM: Direct execution of the user-pinned reference (a light, card-based portfolio dashboard with sidebar nav), translated into Jeffrey's brand and corrected against the craft floor's absolute bans: no kicker/eyebrow copy, no meaningless 01–05 numbering, no uniform same-size icon-cards as page structure, no nested card-in-card chrome. SEED: skipped by design, not by omission — the user supplied a precise visual pin (a reference screenshot) and then explicitly asked to skip further discovery and "just make a skeleton," so no `impeccable concept-seed` roll was run for this surface. This is a deliberate invocation of "the brief wins" against the pinned reference, not an unrecorded gap; no seed key exists because none was rolled.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
