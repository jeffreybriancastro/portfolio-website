## Direction contract

THESIS: One operator runs a client's whole system — site, funnel, CRM, automation — not a single-service specialist. Refuses the "just a web designer" or "just an automation guy" page.

OWN-WORLD: Deep Teal / Warm Cream, each taking both roles: a deep-teal ground with Warm Cream ink by default, inverting to a Warm Cream ground with deep-teal ink in light. One accent, teal, deepened to #1E6A67 so it clears the small-text floor.

STORY: Visitor reads the single-operator capability claim in one line, sees the real tool stack (GHL, n8n, Zapier, Claude Code) as proof of hands-on delivery, scans service breadth as a four-card band (Automation Workflows / CRM / Funnels / Websites), each card showing its stack, a proof tag and three checkpoints, previews clearly-labeled placeholder project slots, meets the person behind it in a full-width About band, reaches the contact CTA within the first two screens.

FIRST VIEWPORT: Left-fixed rail — photographic identity mark (a real head-and-shoulders crop; it replaced the "JC" monogram once the user supplied a portrait), name "Jeffrey Brian Castro", one-line role, socials, nav — beside a hero: two-line bold headline stating the single-operator thesis, one-line subhead, tool-stack strip as one bordered labelled rail spanning the column (no eyebrow label above it), and the primary CTA in the accent color sharing the headline's row at its right. Directly below, still in the first section, a tinted overview panel holds one tile per section of the page — each a preview carrying the real artefact, linking down. The bento composition follows.

FORM: Direct execution of the user-pinned reference (a light, card-based portfolio dashboard with sidebar nav), translated into Jeffrey's brand and corrected against the craft floor's absolute bans: no kicker/eyebrow copy, no meaningless 01–05 numbering, no uniform same-size icon-cards as page structure, no nested card-in-card chrome. SEED: skipped by design, not by omission — the user supplied a precise visual pin (a reference screenshot) and then explicitly asked to skip further discovery and "just make a skeleton," so no `impeccable concept-seed` roll was run for this surface. This is a deliberate invocation of "the brief wins" against the pinned reference, not an unrecorded gap; no seed key exists because none was rolled.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
